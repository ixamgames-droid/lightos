# PROC-19 — die Gates des CI-Schnellwegs fuer reine Doku-/Backlog-PRs.
#
# Aendert ein PR ausschliesslich Doku (tools/geaenderte_dateien_klasse.py sagt
# "doku"), faehrt die CI statt der vollen Suite nur die Testdateien, die hier
# stehen. Lokal: ./tools/verify_loop.sh --doku
#
# Format: je Zeile ein Muster (fnmatch, Gross-/Kleinschreibung zaehlt) auf den
# DATEINAMEN unter tests/. "#" leitet einen Kommentar ein.
# Eine Zeile mit "!" davor nimmt eine Testdatei BEWUSST aus — mit Grund.
#
# Der Waechter tests/test_proc19_doku_schnellweg.py verlangt: jede Testdatei,
# die in ihrem Code (nicht nur im Docstring) eine Doku-Datei nennt, steht hier
# — als Gate oder als Ausnahme. Wer einen neuen Test schreibt, der eine
# Anleitung, den Backlog oder ein Changelog-Fragment liest, traegt ihn als Gate
# ein; sonst wuerde ein Doku-PR ihn auf dem kurzen Weg nie fahren und erst der
# Push nach main (immer volle Suite) wuerde rot.

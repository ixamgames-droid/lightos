### 2026-10-11 — Handy verbinden: QR-Code scannen, Konsole auf den Startbildschirm (WEB-11)

#### Neu / Tests

- **QR-Code fürs Handy.** Sobald das Web-Interface läuft und die Handy-Konsole
  eingeschaltet ist, zeigt LightOS einen QR-Code: klein in der Seitenleiste
  „📱 Handy-Konsole“ (ein Klick vergrößert ihn) und groß im Dialog
  „Web-Remote: Verbindung & Token“. Kamera draufhalten, Link antippen — das Handy
  ist verbunden. Abtippen der Adresse entfällt. Der Code entsteht auf dem PC,
  ohne Internet und ohne zusätzliches Programm.
- **Richtige Netzwerkkarte.** Hat der PC mehrere (WLAN und Kabel, VPN, virtuelle
  Karten), steht unter dem Code die Auswahl „Netzwerkkarte“ mit Name und Adresse;
  LightOS merkt sich die Wahl. Angeboten wird nur, was der PC wirklich hat.
- **Klare Ansage statt eines Codes, der nicht funktioniert:** Läuft das
  Web-Interface nicht, ist es nur auf diesem PC erreichbar, ist die Handy-Konsole
  aus oder gibt es kein Netz, steht dort der nötige Schritt.
- **„Nur im eigenen WLAN zeigen — wer den Code scannt, kann die Handy-Konsole
  bedienen.“** steht neben jedem Code. Der Knopf im Dialog heißt jetzt
  **„Schlüssel erneuern (neues Token)“**: er macht alle alten Codes und Links
  sofort ungültig, der angezeigte Code wechselt mit.
- **Zum Startbildschirm hinzufügen.** Die Handy-Konsole lässt sich am iPhone
  (Teilen → „Zum Home-Bildschirm“) und unter Android (Menü → „App installieren“ /
  „Zum Startbildschirm hinzufügen“) als Symbol ablegen und startet dann im Vollbild
  mit eigenem LightOS-Symbol. Beim ersten Besuch zeigt die Seite dazu einen kleinen,
  wegklickbaren Tipp. Der Schlüssel steht nicht im Symbol; das Handy merkt sich die
  Anmeldung selbst. Nach „Schlüssel erneuern“ zeigt die Seite „Neu verbinden“ —
  neuen Code scannen oder den Schlüssel auf der Seite eintippen.
- Die Seite braucht weiterhin die laufende Verbindung zum Pult; einen
  Offline-Betrieb gibt es nicht.
- **Behoben nebenbei:** Mit zwei Netzwerkkarten lud die Handy-Seite über die
  „andere“ Karte zwar, verband sich aber nie. Der Server nimmt jetzt Verbindungen
  über jede eigene Adresse des PCs an (weiterhin keine fremden Ursprünge).
- Anleitung: [Web-Remote, Abschnitt 6 „Handy verbinden“](docs/anleitung_web_remote/ANLEITUNG.md)
  — QR-Code, Startbildschirm und was bei „Seite nicht erreichbar“ zu prüfen ist.
- Tests: `tests/test_web11_qr_startbildschirm.py` (QR-Code gegen die Norm und drei
  feste Referenzen, Wahl der Adresse, Dialog und Seitenleiste, Manifest und Symbole,
  Schlüssel in keinem Protokoll).

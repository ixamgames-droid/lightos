Prioritaet: P2
Status: review
Titel: Hilfe-Einträge öffnen verlässlich: Bedienhilfen, Windows ohne Programm für `.md`, Sitzungs-Log-Zeile

Herkunft: Windows-Test von UI-85/STAB-33 durch Sitzung D (10.10.2026), drei Befunde. (1) Über UI-Automation ausgelöst („Invoke“ am Menüeintrag — so arbeiten Screenreader und Sprachsteuerung) öffnete „Datenordner öffnen“ KEINEN Explorer, im `crash.log` stand `0x8001010d`: der Klick lief in einem eingabe-synchronen Fensteraufruf, aus dem Windows nichts nach außen startet; aus der Ereignisschleife ausgelöst ging es. (2) „Erste Schritte“/„Anleitungen öffnen“ zeigen im Quellbetrieb auf die lokale `.md` — ein frisches Windows hat dafür kein Programm: es erschien der Dialog „Öffnen mit“ statt der Anleitung, `openUrl` meldete trotzdem Erfolg. (3) `systeminfo.txt` nannte den Pfad des Sitzungs-Logs auch, wenn es die Datei nicht gab (Start ohne Mitschrift, frischer Datenordner bei `--diagnose`).
**Umsetzung (2026-10-10):** (1) `hilfe.oeffne()` reicht `openUrl` über `QTimer.singleShot(0, …)` weiter und meldet „angenommen“; ein Fehlschlag wird gemeldet, reißt nichts ab. (2) `hilfe.doku_ziel()` nimmt die lokale Datei nur, wenn `hat_zugeordnetes_programm()` es bestätigt — unter Windows über `AssocQueryStringW` mit `ASSOCF_INIT_IGNOREUNKNOWN` (ohne das Flag antwortet Windows für JEDE Endung mit „OpenWith.exe“); sonst der Link auf die Projektseite. Außerhalb von Windows und im Zweifel bleibt es beim bisherigen Verhalten. (3) `basis_infos` nennt den Log-Pfad nur, wenn die Datei existiert, sonst „keins (…)“; der Kopfblock des Logs selbst entsteht vor dem Öffnen der Datei und nennt ihn weiter.
**Tests:** `test_ui87_hilfe_oeffnen.py` (14 Fälle, auf `main` 13 rot; die Zuordnungsfrage ist austauschbar, damit der Fall auf jedem Betriebssystem läuft, dazu ein Fall am echten Windows); `test_ui85_hilfe_menue.py` an das Öffnen über die Ereignisschleife angepasst.
**Nicht behoben:** ohne Internet zeigt der Browser beim Rückfall auf die Projektseite eine Fehlerseite — die Anleitung in der App anzuzeigen wäre der nächste Schritt.

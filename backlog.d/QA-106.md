Status-Notiz: Vorwarnung ohne Bildschirm ohne Fenster; sysfs-Nachbau nur unter Linux; Raster-Mitte am Rand statt QRect.center gemessen
Nach: QA-105
Titel: Drei Tests unter Windows 11 x64 rot oder haengend — Vorwarnung modal, sysfs-Ordner mit ':' und Raster-Mitte 1 px

**Herkunft:** volles Windows-Gate von Sitzung D am 29.10.2026 auf main 674fa9c6 (Windows 11 x64), alle drei stabil und einzeln nachgestellt. Unter Linux gruen.
**1 — `tests/test_input_reconfigure_cleanup.py` haengt 60 s bis zum Timeout.** Ursache: Der Haken „…-Eingang aktivieren“ ruft `EmpfangsBox.vorwarnen`; unter Windows (`netz_hinweis.loest_abfrage_aus`) oeffnet `_zeige_vorwarnung` das modale `QMessageBox.information` „Gleich fragt Windows nach“ (OUT-79), das headless niemand schliesst. Denselben Weg geht jeder Test, der `OutputConfigDialog` baut und einen Eingangs- oder Fernsteuerungs-Haken setzt. Fix (zentral, im Produkt): `_zeige_vorwarnung` zeigt ohne Bildschirm (`qt_plattform.ohne_bildschirm`, die Plattform, auf der Qt wirklich laeuft) kein Fenster, sondern schreibt eine Zeile ins Protokoll — dieselbe Regel wie beim Wiederherstellungsdialog (QA-23/STAB-34). In der sichtbaren App unveraendert; Tests, die die Vorwarnung pruefen, ersetzen `_zeige_vorwarnung` weiterhin. Tests: `test_vorwarnung_ohne_bildschirm_oeffnet_kein_fenster` und `test_haken_unter_windows_haengt_nicht` in `tests/test_out79_firewall_hinweis_ui.py` (mit nachgestelltem Windows ohne Fix rot).
**2 — `tests/test_out70_interface_erkennung.py::test_sysfs_wird_gelesen_hubs_bleiben_draussen`: WinError 267.** Ursache: Der Test baut einen sysfs-Baum mit Schnittstellen-Ordnern wie `1-2:1.0` und einem `driver`-Symlink; unter Windows ist ':' im Namen verboten (Symlinks brauchen dort zudem Sonderrechte). Testfehler: Das Produkt liest sysfs nur unter Linux (`interfaces.erkenne`, unter Windows pyusb). Fix: Der Nachbau-Test wird nur unter Windows uebersprungen (sonst Abdeckung unveraendert); neu `test_sysfs_nur_unter_linux` laeuft auf jedem System und belegt, dass die Erkennung unter Windows `lies_sysfs` nie aufruft.
**3 — `tests/test_ui105_raster_beschriftung.py::ZellTextLageTest::test_zu_kleine_zelle_laesst_namen_weg`: 12 != 13.** Ursache: Ganzzahl-Rundung im Test, nicht im Produkt. Segoe UI hat unter Windows gerade Zeilenhoehen (unter Linux die Ersatzschrift ungerade); dann ist der Restplatz in der Zelle ungerade, die wahre Mitte liegt auf einem halben Pixel, und `QRect.center()` rundet zusaetzlich ab. `zell_text_rechtecke` zentriert richtig (Rand oben und unten unterscheiden sich um hoechstens 1 px). Fix: Der Test vergleicht die beiden Raender (Unterschied 0 oder 1 px, Begruendung im Test) statt `center()`; die eigentliche Pruefung (zu kleine Zelle laesst den Namen weg, genau passende zeigt beide) bleibt. Gegenprobe: eine um 2 px verschobene Nummer faellt durch.

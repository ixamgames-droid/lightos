ID: VCB-42
Prioritaet: P2
Status: review
Titel: Blackout-Ziel: gelöschte Gruppen-Nummer wird wiederverwendet; Nummern gelten nur in einer Show
Nach: VCB-36

**Herkunft:** Review von VCB-36 (#1025). (a) SQLite vergibt die höchste Nummer neu: letzte Gruppe löschen, neue anlegen — die neue Gruppe erbte das Ziel der Blackout-Taste. (b) „VC Layout speichern/laden“ trägt die Nummern in eine andere Show, wo sie einer anderen Gruppe gehören.
**Umsetzung (2026-10-11):** Name + Ordner je Nummer mitzuspeichern und zu vergleichen reicht allein nicht — für einen Namensvergleich sehen „umbenannt“ und „gelöscht und neu angelegt“ gleich aus, die Zusage aus VCB-36 (Umbenennen ändert das Ziel nicht) wäre gebrochen. Deshalb trägt jede Gruppe zusätzlich eine **Kennung** (`fixture_groups.uid`; Show-DB per `migrate_show_db`, `.lshow` speichert und lädt sie; bewusst keine Pflichtspalte, damit eine ältere Programmversion auf derselben Show-DB weiter Gruppen anlegen kann): sie bleibt beim Umbenennen und Verschieben, jede neu angelegte Zeile bekommt über den Modell-Default eine neue — also an allen Stellen, die Gruppen anlegen. Die Taste merkt je Nummer den Steckbrief (Kennung, Name, Ordner; Feld `blackout_group_refs`). Regel in `src/core/group_ref.py`: gleiche Kennung → dieselbe Gruppe; sonst gleicher Name im selben Ordner → gilt als dieselbe; sonst **verloren** — schaltet nichts, nie global. Sichtbar: rot gestrichelter ⚠-Rahmen mit Tooltip auf der Taste, Hinweis in der Statusleiste beim Drücken, im Dialog eine eigene Zeile „— verloren …“ (OK bindet die Taste nicht an die fremde Gruppe). Der State prüft den Steckbrief bei jedem Auflösen, also auch für eine gehaltene Taste. Undo gibt der Kopf-Gruppe ihre Kennung zurück. Layouts aus dem VCB-36-Zwischenstand (nur Nummern) gelten über die Nummer und bekommen den Steckbrief beim Laden. Für ältere Programmversionen steht bei einem verlorenen Ziel ein Platzhalter in `blackout_groups`, nicht der Name der fremden Gruppe. Tests `tests/test_vcb42_blackout_ziel_wiedererkennen.py` (56 Fälle, ohne Fix 44 rot).
**Grenze, mit VCB-44 aufgehoben:** eine gelöschte und unter gleichem Namen im selben Ordner neu angelegte Gruppe galt als dieselbe; seit VCB-44 entscheidet allein die Kennung, sobald beide Seiten eine tragen.

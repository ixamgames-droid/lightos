Titel: Live-Editor der Virtual Console: gleiche Parameter mehrerer Effekte gemeinsam einstellen (z. B. Farbwechsel-Reihenfolge)

**Herkunft:** Wunsch des Projektinhabers, 02.11.2026. **Heute:** Das Live-Edit-Panel (`src/ui/virtualconsole/vc_multi_live_editor.py`, VC-Widget) nimmt mehrere Effekte per Drag&Drop auf, zeigt aber immer nur EINEN Effekt zur Zeit (Dropdown bzw. –/+ zum Blättern); jeder Regler wirkt nur auf den gerade gewählten Effekt. **Soll:** Wenn mehrere Effekte im Panel denselben Parameter unterstützen (z. B. Farbwechsel-Reihenfolge/Farbliste, Richtung, Geschwindigkeit/Tempo-Faktor, Breite, Fade), kann man sie gemeinsam bearbeiten: eine Ansicht „Gemeinsam“ (oder Mehrfachauswahl der Effekte im Panel) zeigt nur die Parameter, die alle gewählten Effekte haben, und eine Änderung wirkt auf alle gleichzeitig. Unterschiedliche Ausgangswerte sichtbar machen (z. B. „gemischt“), relative Änderung bei Zahlenwerten prüfen. Gleiche Live-Semantik wie heute (Baseline/Preset bleibt, Werte über `effect_live`), ein Rückgängig-Schritt je Änderung. **Vor dem Bau:** kurz klären, welche Parameter typübergreifend „gleich“ sind (Matrix/Chaser/EFX haben teils verschiedene Namen für dasselbe), und einen Entwurf der Bedienung zeigen. **Fertig, wenn:** zwei Matrix-Farbwechsel im Panel per einer Änderung dieselbe neue Farbreihenfolge bekommen und ein EFX daneben nur die passenden gemeinsamen Regler zeigt; Test dafür.

Titel: Gesten-Dialog: Hinweis, dass Windows das Drei-Finger-Tippen selbst abfaengt

**Herkunft:** Finger-Probe von B (Windows 11, 15.11.2026), Zuteilung A: Drei-Finger-TIPPEN kommt unter Windows 11 nie in der App an (Systemgeste), drei Finger beim Ziehen schon.

**Stand 16.11.:** den Hinweis liefert inzwischen UI-136 (4) (#1305, `src/ui/system_gesten.py`): eine Zeile oben im Dialog „Touch-Gesten“ nennt unter Windows die Systemgeste und die Einstellung, mit der man sie abschaltet. Der eigene Hinweis von UI-134 (ein zweites Etikett unter der Drei-Finger-Auswahl in `src/ui/widgets/gesten_dialog.py`) ist deshalb aus diesem PR wieder entfernt - mit beiden staenden zwei Hinweise zum selben Thema im Dialog, mit verschieden geschriebenen Namen der Einstellung („Toucheingabe“ gegen „Touch → Drei- und Vier-Finger-Touchgesten“). `tests/test_ui134_gesten_windows_hinweis.py` haelt fest, dass es unter Windows genau EIN Hinweis ist und dass er die Einstellung nennt.

**Offen (Leitung/B):** der Text von UI-136 steht auch unter Windows 10, wo es den genannten Einstellungs-Pfad nicht gibt (Hinweis der Leitung zu #1300: „Windows 11:“ voranstellen); den genauen Namen der Einstellung bitte am Windows-11-Geraet ablesen.

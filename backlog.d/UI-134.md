Titel: Gesten-Dialog: Hinweis, dass Windows das Drei-Finger-Tippen selbst abfaengt

**Herkunft:** Finger-Probe von B (Windows 11, 15.11.2026), Zuteilung A: Drei-Finger-TIPPEN kommt unter Windows 11 nie in der App an (Systemgeste), drei Finger beim Ziehen schon.

**Umsetzung:** `src/ui/widgets/gesten_dialog.py` zeigt nur unter Windows unter der Drei-Finger-Auswahl einen Hinweis: Windows nutzt das Tippen mit drei Fingern als Systemgeste; Abhilfe in den Windows-Einstellungen (Bluetooth und Geraete -> Toucheingabe) die Drei- und Vier-Finger-Gesten ausschalten; LightOS aendert das nicht selbst. Den genauen Namen der Einstellung bitte am Windows-11-Geraet gegenpruefen. Test `tests/test_ui134_gesten_windows_hinweis.py` (ohne Fix rot).

**Gegenpruefung der Leitung zu #1300 (16.11.):** der Hinweis beginnt jetzt mit "Windows 11:" - den genannten Einstellungs-Pfad gibt es unter Windows 10 nicht. Test nachgezogen (ohne Aenderung rot).
